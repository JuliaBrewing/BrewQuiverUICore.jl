View data and layout

Frontends render plain data with Unitful quantities, missing where a value does not apply, and format them at the last moment.

Formatting and parsing

format shows a quantity with the decimals of its unit (display_digits), in a display unit (display_unit: grams below a kilogram, millilitres below a litre):

format.([1.0523u"sg", 23.14u"L", 0.3u"kg", 5.23u"percent", 34.6u"IBU", 4u"L/hr", 60u"minute"])
7-element Vector{String}:
 "1.052 sg"
 "23.1 L"
 "300 g"
 "5.2%"
 "35 IBU"
 "4.0 L/h"
 "60 min"

parse_value reads what users type, and what format writes:

parse_value.(["4.8 kg", "95%", "70 min", "4 L/h", "10 min remaining", "–"])
6-element Vector{Any}:
  4.8 kg
 95.0 %
 70.0 minute
  4.0 L hr^-1
   Remaining(10.0 minute)
   nothing

A number typed without a unit is in the unit of the value it replaces, as shown (input_unit): no unit is guessed from its size.

parse_value("25", 27.0u"L"), parse_value("2500 mL", 27.0u"L"), parse_value("250", 0.3u"kg")
(25.0 L, 2500.0 mL, 250.0 g)

Preferred units

Each kind of quantity (a role: the amounts of malts, of hops, of cultures, of salts; volumes, temperatures, gravities, colors, absorptions, rates) is shown and typed in the unit of the UnitPreferences of the session (UNIT_CHOICES lists the choices). Frontends read them from a configuration file shared by all of them (load_units, save_units, units_path).

us = UnitPreferences(fermentable = u"lb", hop = u"oz", volume = u"gal", temperature = u"°F",
                     gravity = u"°P")
s2 = Session(single_batch(); units = us)
x = node_summary(s2, :wort)
(node_summary(s2, :pale).contents, format(s2, x.volume), format(s2, x.gravity),
 format(s2, x.temperature))
("9.92 lb Pale ale malt", "6.22 gal", "13.1 °P", "212 °F")

A number typed without a unit is in the unit shown, or for an empty field in the preferred unit of its role:

(parse_value(s2, "10", 4.5u"kg"; role = :fermentable), parse_value(s2, "1.5", nothing; role = :hop))
(10.0 lb, 1.5 oz)

Nodes and arrows

x = node_summary(s, :wort)
(x.kind, format(x.volume), format(x.gravity), format(x.ibu), x.color)
(:stage, "23.5 L", "1.053 sg", "22 IBU", "#ef9600")
[(a.source, a.destination, a.index, a.kind, format(a.moved_mass)) for a in arrow_summaries(s)][1:4]
4-element Vector{Tuple{Symbol, Symbol, Int64, String, String}}:
 (:pale, :mash, 1, "Transfer", "4.50 kg")
 (:crystal, :mash, 1, "Transfer", "300 g")
 (:cascade, :kettle, 1, "Transfer", "25 g")
 (:cascade, :kettle, 2, "Transfer", "25 g")

node_color is the user's color, or the color of the beer from its SRM, or that of the malt of a lot. vessel_groups groups the nodes by vessel, the lots first:

vessel_groups(s)
5-element Vector{Pair{Union{Nothing, Symbol}, Vector{Symbol}}}:
    nothing => [:pale, :crystal, :cascade, :yeast, :strike_water, :sparge_water, :priming_sugar]
   :mashtun => [:mash, :rested, :grain_bed]
    :kettle => [:kettle, :wort, :chilled]
 :fermentor => [:fermentor, :beer]
   :bottles => [:bottling, :bottles]

node_detail has everything an inspector shows: the summary, the initial contents, the contents and leftover in the brew (with solid_rows, liquor_rows and mineral_rows), and the arrows in and out.

[(r.name, format(r.amount), format(r.timing)) for r in solid_rows(node_detail(s, :kettle).contents)]
2-element Vector{Tuple{String, String, String}}:
 ("Cascade", "25 g", "60 min remaining")
 ("Cascade", "25 g", "10 min remaining")

fields describes the fields of an arrow or of equipment, for forms, with the units they accept:

[(f.label, format(f.value), string.(f.units), f.optional ? "optional" : "") for f in fields(Boil())]
4-element Vector{Tuple{String, String, Vector{String}, String}}:
 ("time", "60 min", ["minute"], "")
 ("evaporation", "–", ["L hr^-1", "hr^-1"], "optional")
 ("stand", "0 min", ["minute"], "")
 ("stand temperature", "80.0 °C", ["°C"], "")

solution_rows shows the solution of a Solve:

sol = apply!(s, Solve(:fermentor => gravity => 1.050u"sg", Amount(:pale, :crystal)))
[(t.node, t.quantity, format(t.goal), format(t.reached)) for t in solution_rows(sol).targets]
1-element Vector{Tuple{Symbol, String, String, String}}:
 (:fermentor, "gravity", "1.050 sg", "1.050 sg")

Layout

layout places each node in the layer of its longest path from a source (a lot just before its first destination), and orders the layers by barycenters, keeping the nodes of each vessel together:

p = layout(quiver(s))
[n => p[n] for n in (:pale, :mash, :kettle, :wort, :fermentor)]
5-element Vector{Pair{Symbol, Vector{Float64}}}:
      :pale => [0.0, 0.0]
      :mash => [1.0, 0.0]
    :kettle => [4.0, 0.0]
      :wort => [5.0, 0.0]
 :fermentor => [7.0, 0.0]

layout! writes the positions into the nodeviews as one undoable step, and positions gives the stored positions, or the layout for the nodes without one. crossings counts the arrows that cross:

crossings(quiver(s), p)
0
